# Вызовы порталов рабочего стола

Адаптация [rymdport/portal](https://github.com/rymdport/portal), версия `v0.4.2`.
Исходная лицензия MIT сохранена в [LICENSE](LICENSE).

Обёртки используют `github.com/Uzer007-admin/dbus/v5`, поэтому приложения Granio
и портальные операции работают с согласованными типами D-Bus и исправленным
транспортом. Названия интерфейсов и формат протокола порталов сохранены.

Наблюдение за системной темой и расширениями KDE предоставляется отдельно
пакетом `github.com/Uzer007-admin/dbus/v5/portal`.
